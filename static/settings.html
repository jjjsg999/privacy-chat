Sensitive terms

One term per line. Optionally use an uppercase type such as CLIENT, PERSON, SYSTEM or REGULATOR followed by a colon. Plain terms use SENSITIVE tokens. Matching ignores case and respects word boundaries. Lines starting with # are comments.

Changes apply to the full history on the next message in every conversation.

Custom instructions

Added to the assistant’s system prompt for normal chat and meeting questions on that channel. They pass through the same privacy processing as your messages. Meeting analysis and Adviser chats are not affected. Up to 2,000 characters each.

File uploads

Off by default: extracted text is sent with your message, then privacy-processed like anything you type. Turn this on to read and correct the text first. This is useful because OCR can misread characters, and a misread name may escape detection. Word and plain-text files are always read exactly and are never previewed.

Files are read on this computer (English and Traditional Chinese OCR) and are never stored. Default limits: 10 MB per file, 20 PDF pages, 5 files per message; they can be raised under "upload_limits" in data/settings.json.

Spaces

Spaces group your chats so the sidebar shows one set at a time. They are for organising only: nothing is shared between chats, and privacy works exactly the same in every space.

    Context

    Lean sends about 12,000 tokens of conversation: the cheapest, but older material is left out sooner. Balanced sends about 30,000. Full sends everything the model can take. Whatever is left out is shown under each reply, and you can pin any item to keep it in every request. Meetings always include the full transcript.

    Chat diagnosis

    Records the exact text sent for new meeting analyses. Open Full transcript to compare the original with the privacy-processed system prompt and transcript. Older meetings without a recording cannot show an exact API version. Disabling hides existing recordings and stops new recordings; saved recordings remain local.
